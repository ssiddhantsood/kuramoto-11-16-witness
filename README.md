# Finite Kuramoto witness above \(11/16\)

This repository contains a compact, reproducible specification of a finite
simple unweighted graph whose homogeneous Kuramoto model has a strict
nonsynchronous equilibrium.

## Result

- Vertices: \(N=460{,}800\)
- Edges: \(74{,}003{,}856{,}975\)
- Minimum degree: \(\delta=316{,}802\)
- Exact connectivity:

  \[
  \mu=\frac{\delta}{N-1}
  =\frac{316802}{460799}
  =0.6875058322609207\ldots
  >\frac{11}{16}.
  \]

The comparison is exact:

\[
16\delta-11(N-1)=43>0.
\]

At the recorded six-class equilibrium:

- the printed phase decimals have torque residual below
  \(1.3\times10^{-85}\), and independent Newton refinement reaches
  \(1.7\times10^{-156}\);
- the order parameter is approximately \(0.0321\), so the state is
  nonsynchronous;
- the Hessian has exactly one zero eigenvalue, generated by global rotation;
- the absolute Hessian gap is approximately \(48.74396\);
- the normalized gap is approximately \(1.0578\times10^{-4}\);
- a block-operator comparison proves every transverse eigenvalue is at least
  \(102{,}332.59\).

Thus the equilibrium is a strict local minimum of the analytic Kuramoto
potential modulo rotation, hence locally asymptotically stable modulo
rotation.

## Repository contents

- `graph_spec.json` — exact compact graph and phase specification.
- `verify_witness.py` — standalone verifier. It imports no exploratory search
  code and reads only `graph_spec.json`.
- `verification_report.json` — output from a clean verifier run.
- `INDEPENDENT_AUDIT.md` — adversarial from-scratch audit and mode accounting.
- `audit_verdict.json` — machine-readable independent verdict.

The graph has more than 74 billion edges, so storing an explicit edge list is
unnecessary. It consists of six clique fibers. A partial cross block between
classes \(i<j\) is defined using

```text
(v - u - shift_start) mod gcd(n_i, n_j) < shift_count
```

for local vertex labels `u` and `v`. This is an exact simple biregular
bipartite construction and gives an \(O(1)\) adjacency oracle.

## Independent audit

An adversarial audit reconstructed the graph before reading the original
certificate and returned `CONFIRMED`:

- all 460,800 loop checks and 60,000 random adjacency queries passed;
- exact class degrees, edge count, connectivity, and threshold excess agree;
- an independent 160-digit Newton solve reached residual
  \(1.60\times10^{-156}\);
- outward-rounded quotient bounds keep the nontrivial gap strictly positive;
- a separately derived unequal-fiber Fourier decomposition accounts for all
  \(460{,}794\) transverse dimensions, with minimum
  \(111{,}089.5637903687\);
- independent compact and Fourier Hessian matvecs agree below
  \(4\times10^{-16}\);
- independent nonlinear tests confirm local return.

The basin is finite: coherent weak-mode perturbations of RMS \(10^{-2}\) can
converge to synchrony, while tested amplitudes through \(10^{-3}\) return.
This does not affect local asymptotic stability, which is the witness
criterion.

## Why the transverse bound is complete

The six-class partition is equitable, so the Hessian splits into:

- a six-dimensional class-constant quotient; and
- the orthogonal sum of the zero-sum subspaces inside each class, of total
  dimension \(\sum_i(n_i-1)=460{,}794\).

On the latter subspace:

- a clique on class \(i\) contributes \(n_i I\);
- a complete cross block vanishes between class-zero-sum vectors;
- a partial \((d_{ij},d_{ji})\)-biregular block has adjacency operator norm at
  most \(\sqrt{d_{ij}d_{ji}}\).

The verifier assembles the resulting \(6\times6\) comparison matrix. Its
smallest eigenvalue exceeds \(102{,}332\), proving positivity of the entire
transverse subspace without materializing the graph or relying on sampled
Fourier modes.
